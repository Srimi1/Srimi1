I'm **Srijan**, a developer and student in India. I build native desktop and mobile
apps — mostly things I wanted to exist and couldn't find — and the agent tooling that
helps me build them faster.

The habit I care about most: **ship it properly.** Signed builds, a quality gate that
runs before anything lands, real release notes, and a README that tells you what the
thing *cannot* do as clearly as what it can.
