# Profile artwork and assets

The profile combines Srijan's original avatar with Sarah, his AI companion from Sera. Both character identities and the existing duo artwork are preserved. The main artwork is a still image; the small typing introduction is the only profile animation.

Layout inspiration: [beautify-github-profile](https://github.com/rzashakeri/beautify-github-profile), including its suggestions for badges, introductions, widgets, and [typing SVGs](https://github.com/DenverCoder1/readme-typing-svg). The profile uses an original locally hosted text animation and the existing character art.

The rejected story GIF, its simulation, game runtime, and GIF export workflow have been removed. Earlier versions and source art remain recoverable in Git history. Existing unused character encodings and sprite source images remain preserved as assets; they are not used by the portfolio.
