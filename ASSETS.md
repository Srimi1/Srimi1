# Profile artwork and assets

The profile combines Srijan's original avatar with Sarah, his AI companion from Sera. Both character identities and the existing duo artwork are preserved. The current profile uses a static, theme-aware identity banner and preserves the still duo artwork. Historical typing and hero assets remain available but are no longer shown in the README.

The rejected story GIF, its simulation, game runtime, and GIF export workflow have been removed. Earlier versions and source art remain recoverable in Git history. Existing unused character encodings and sprite source images remain preserved as assets; they are not used by the portfolio.
