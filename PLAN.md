# Signal / Run delivery

Replace the profile's autoplay video with an original game that pairs the existing avatar and recovered Sarah character. Keep the existing project identities and publish the game through the profile's existing GitHub Pages site.

## Delivered design

A static anime duo cover opens a manually controlled rooftop action platformer. Three sectors, memory recovery, drones, dash attacks, Sarah's pulse, an advancing story, and a final Guardian provide a complete win/lose/retry loop. Keyboard and touch controls, pause, optional synthesized audio, fullscreen, reduced motion, assist mode, and separate local scores are included.

## Validation

Sixteen rule and parser tests cover the core behavior, including complete victories in standard and assist mode. Real desktop and phone browser checks cover input, progression, persistence, pause, overlay focus, layout, and error-free rendering. The deploy workflow repeats the relevant checks before publishing. The original avatar's SHA-256 and Sarah's Git blob identify the preserved source assets.
